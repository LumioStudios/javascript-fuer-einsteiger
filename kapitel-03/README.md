## So führst du die Beispiele aus

**Mit Node.js** (alle `.js`-Dateien ohne HTML-Partner):

1. Öffne den Ordner `kapitel-03` in VS Code.
2. Öffne das Terminal über *Terminal* › *Neues Terminal*.
3. Gib zum Beispiel ein:

```text
node 3-1-variablen.js
```

**Im Browser** (alle `.html`-Dateien):

1. Klicke doppelt auf die HTML-Datei.
2. Drücke `F12` und wähle den Reiter *Konsole*.

## Fehler zum Ausprobieren

Einige Dateien enthalten auskommentierte Zeilen, die absichtlich einen Fehler auslösen. Sie sind mit `// FEHLER:` markiert. Entferne die beiden Schrägstriche vor der Codezeile, führe die Datei aus und lies die Fehlermeldung. Setze die Schrägstriche danach wieder davor.

## Tipp

Am meisten lernst du, wenn du die Beispiele zuerst selbst abtippst und erst danach mit diesen Dateien vergleichst.
