## Code herunterladen

**Ohne Git:** Klicke oben auf den grünen Button **Code** und wähle
**Download ZIP**. Entpacke die Datei in einen Ordner deiner Wahl.

**Mit Git:**

```bash
git clone https://github.com/LumioStudios/javascript-fuer-einsteiger.git
```

## Beispiele ausführen

Es gibt zwei Arten von Beispielen:

**1. `.js`-Dateien ohne HTML** laufen mit Node.js:

```bash
node kapitel-03/3-1-variablen.js
```

**2. Beispiele mit einer `.html`-Datei** öffnest du im Browser:

1. Doppelklicke auf die `.html`-Datei.
2. Drücke **F12** und wähle den Reiter **Konsole**.

> **Tipp:** In Visual Studio Code kannst du mit der Erweiterung
> *Live Server* HTML-Dateien direkt aus dem Editor öffnen.

## Was du brauchst

- einen aktuellen Browser (Chrome, Firefox, Edge oder Safari)
- einen Editor, z. B. [Visual Studio Code](https://code.visualstudio.com/)
- [Node.js](https://nodejs.org/) (LTS-Version)

Alles kostenlos. Wie du es einrichtest, steht in Kapitel 1.
