# Kapitel 1: Was ist JavaScript?

Begleitcode zum Buch **„JavaScript für Einsteiger – Programmieren lernen Schritt für Schritt“** (Lumio Studios, 1. Auflage 2026).

In diesem Kapitel richtest du deine Werkzeuge ein: Visual Studio Code, die Browser-Konsole und Node.js. Die meisten Beispiele tippst du direkt in die Konsole. Deshalb gibt es hier nur die Lösungen zu den Übungen als Dateien.

## Inhalt

| Datei | Übung | Ausführen mit |
|---|---|---|
| `loesungen/uebung-1-1_rechnen.js` | 1.1 Rechnen in der Konsole | Node.js |
| `loesungen/uebung-1-2_texte-verbinden.js` | 1.2 Texte verbinden | Node.js |
| `loesungen/uebung-1-3_alter.js` | 1.3 Die Werkzeuge prüfen | Node.js |
| `loesungen/steckbrief.js` | 1.4 Ein Steckbrief in einer Datei | Node.js |
| `loesungen/steckbrief-fehler-1.js` | 1.5 Fehler 1: `Console` mit großem C | Node.js |
| `loesungen/steckbrief-fehler-2.js` | 1.5 Fehler 2: fehlendes Anführungszeichen | Node.js |

> **Hinweis:** In der Konsole reicht es, `24 * 60` einzutippen. In einer Datei brauchst du `console.log(24 * 60)`, sonst siehst du kein Ergebnis.

> **Achtung:** Die beiden Dateien `steckbrief-fehler-…` enthalten absichtlich Fehler. Sie sollen beim Ausführen eine Fehlermeldung zeigen.

## So führst du die Lösungen aus

1. Öffne den Ordner `kapitel-01` in VS Code.
2. Öffne das Terminal über *Terminal* › *Neues Terminal*.
3. Gib zum Beispiel ein:

```text
cd loesungen
node steckbrief.js
```
