## So startest du die Beispiele

**HTML-Dateien im Browser:**

1. Klicke im Dateimanager doppelt auf die HTML-Datei.
2. Drücke `F12` (macOS: `Cmd + Option + I`).
3. Wähle den Reiter *Konsole*.

**JS-Dateien mit Node.js:**

1. Öffne in VS Code das Terminal über *Terminal* › *Neues Terminal*.
2. Wechsle in diesen Ordner, zum Beispiel mit `cd kapitel-02`.
3. Starte die Datei, zum Beispiel mit `node console-log.js`.

> **Hinweis:** `alert`, `prompt` und `confirm` gibt es nur im Browser. Die Dateien `dialoge.js` und `uebungen/uebung5.js` funktionieren deshalb nicht mit Node.js.
