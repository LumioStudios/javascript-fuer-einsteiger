## So führst du die Beispiele aus

**Mit Node.js:**

1. Öffne den Ordner `kapitel04` in VS Code.
2. Öffne das Terminal über *Terminal › Neues Terminal*.
3. Führe eine Datei aus, zum Beispiel:

```text
node 4-1_rechenoperatoren.js
```

**Im Browser:**

1. Öffne den Ordner `browser` im Dateimanager.
2. Klicke doppelt auf `index.html`.
3. Öffne mit `F12` die Konsole und lade die Seite mit `F5` neu.

`prompt` gibt es nur im Browser. Die Beispiele im Ordner `browser` und die Lösung zu Übung 4.5 (`loesungen/uebung-4-5/index.html`) funktionieren deshalb nicht mit Node.js.
